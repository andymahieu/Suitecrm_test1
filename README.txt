EventResources Module for SuiteCRM
===============================

This module provides CRUD functionality for Event Resources tables.

Installation Instructions:
-------------------------
1. Log in to your SuiteCRM instance as an administrator
2. Go to Admin > Module Loader
3. Click "Choose File" and select the EventResources.zip package
4. Click "Upload"
5. Click "Install" for the EventResources package
6. Follow the on-screen instructions to complete the installation

Features:
--------
- Full CRUD operations for Event Resources
- Dashlet for quick access to Event Resources
- Integration with SuiteCRM security model
- Support for all standard SuiteCRM views (list, detail, edit)

Tables:
-------
The module creates the following tables:
1. eventresources - Main table for storing Event Resource data
2. securitygroups_eventresources - Relationship table for security groups

Fields:
-------
The module includes fields from both EventResource11 and EventResource12 tables:
- UID
- ARGB Color
- Pattern
- Daily Calendar ID
- Event Creation Rule ID
- Last Post Date
- Last Post User Name
- Hourly Calendar ID
- External Data
- Rub103, Rub75, Rub76, Rub81, Rub150
- Open Forum flag
